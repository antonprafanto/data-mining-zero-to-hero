# 🌐 Direktori Aplikasi Web Interaktif (Streamlit)

Direktori ini berisi kode antarmuka web interaktif yang mendemonstrasikan aspek **Fullstack** dari kurikulum data mining ini.

## 🚀 Cara Menjalankan Secara Lokal

1. Pastikan dependensi sudah terinstal:
   ```bash
   pip install -r ../requirements.txt
   ```
2. Jalankan aplikasi Streamlit:
   ```bash
   streamlit run app.py
   ```
3. Browser Anda akan terbuka secara otomatis di alamat `http://localhost:8501`.

## ☁️ Deployment ke Streamlit Community Cloud (Gratis)
1. Buka [share.streamlit.io](https://share.streamlit.io/).
2. Hubungkan dengan akun GitHub Anda.
3. Pilih repositori `antonprafanto/data-mining-zero-to-hero`, branch `main`, dan file path `app/app.py`.
4. Klik **Deploy**!
