# 📂 Direktori Dataset & Sumber Data Publik

Direktori ini digunakan untuk menyimpan sampel dataset berukuran kecil yang digunakan dalam latihan, serta daftar rujukan dataset publik untuk Capstone Project.

## 🌐 Sumber Dataset Publik Berkualitas Tinggi
1. **[Kaggle Datasets](https://www.kaggle.com/datasets)**: Platform kompetisi data terbesar dengan jutaan dataset nyata dari berbagai industri.
2. **[UCI Machine Learning Repository](https://archive.ics.uci.edu/)**: Sumber dataset akademik standar yang sangat bersih untuk tolok ukur (*benchmark*) algoritma data mining.
3. **[Satu Data Indonesia](https://data.go.id/)**: Portal data terbuka resmi pemerintah Indonesia (sektor kependudukan, kesehatan, ekonomi).
4. **[Google Dataset Search](https://datasetsearch.research.google.com/)**: Mesin pencari khusus dataset di seluruh web.

## ⚠️ Catatan Penting
- Jangan mengunggah (*commit*) dataset mentah berukuran besar (>50 MB) langsung ke repositori GitHub.
- Untuk dataset berukuran besar di Google Colab, gunakan tautan unduh langsung via `wget`, `curl`, atau simpan di Google Drive pribadi Anda.
